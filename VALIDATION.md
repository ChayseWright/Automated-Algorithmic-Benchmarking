# Validation record — software 4.0

Date: November 12, 2026.

## Executed in the authoring environment

- `python validation/check_structure.py`: lexical/bracket/block and primary-function-name audit over all MATLAB source files. This is **not** a MATLAB parser.
- `python validation/check_numerics.py`: independent PSD normalization, DPSS equations against SciPy, gain invariance, gap support, guarded-observer locality, variance/power identities and Gaussian-AM expectation checks.
- `python validation/check_study_numerics.py`: independent anti-alias design, amplitude/phase tests including fractional rates, rejection, pure-FM carrier preservation, gap/clock propagation, demodulation order, balanced ridge logistic reference optimization, threshold ties, ordinal-loss identities and explicit package-symbol resolution.
- `python validation/check_revision3_numerics.py`: independent full-record pooled covariance, MUSIC/ESPRIT/pencil recovery of a late 6-Hz burst with a gap, complete atomic-block/tail coverage, IRASA warp amplitude/frequency, DPSS parameter repair, coverage-anchor values and explicitly labelled source-wiring inspections.
- `python validation/check_motion_numerics.py`: independent fractional-rate motion amplitude/phase preservation, invalid-gap guards, affine clock/drift, signed vector PSD and rotation invariance, harmonic/HAC power equations, a geometry-preserving switching-oscillator witness, abstention/unknown-state denominators, MIMO destructive interference/rank, held-out target invariance and the limits of variance/PSD compression. Motion-specific source wiring is inspected separately and labelled as inspection.

Exact numerical output is in `validation/numerical_checks.json`, `validation/study_numerical_checks.json`, `validation/revision3_numerical_checks.json` and `validation/motion_numerical_checks.json`. These scripts implement/reference equations in Python; they do **not** execute the MATLAB source. MATLAB file counts and explicit symbol counts are regenerated by the checks. `python validation/run_validation.py` reruns all five checks and writes the release validation summary.

The independent anti-alias reference met at least 91 dB rejection at 1,000/1,111/2,500 Hz and about 0.0003 dB passband error. The reference pure-FM carrier RMS error was about 1.38e-6. This does not establish native runtime correctness or clinical performance.

The added subspace equation check recovered a 20–28 s burst at 6.0000 Hz (MUSIC), 6.0013 Hz (ESPRIT) and 6.0012 Hz (matrix pencil), using all 2,980 valid samples. The atomic-block coverage check passed 20 length/block combinations. IRASA warped-tone gains differed from unity by less than 1e-5 in the tested cases. These are independent equations and finite examples, not execution of the corresponding MATLAB files or a clinical accuracy claim.

The motion equation checks test native rates 33.3/60/125/333 Hz, preserving 3/6/9-Hz tones with absolute gain error below 0.00003 in these cases and measured rejection >=90 dB. A signed 3-D target with known mean square 0.52 yielded about 0.51949 after guarded spectral integration; orthogonal coordinate rotation changed its PSD by less than 1e-12. These finite software checks do not establish real motion-capture noise limits, natural burst recall, calibrated search-wide confidence or clinical accuracy.

The source audit covers 312 MATLAB files. Software 4 adds 16 core motion test functions and two optional integration/cache tests in `tests/run_motion_tests.m`; their presence is not a claim that they passed native execution.

## Scope boundaries

The 75-case development generator and synthetic integration tests cannot establish all natural-artifact or motor-unit physiological behavior. Labelled clinical participants supply clinical references, not exact natural episode timestamps or latent electrical-source power. The repeated-burst first/last boundary errors are record-span summaries, not matched-event localization tests.

Missing backend wrappers are explicitly unavailable rather than concealed by generic placeholder estimates. Five learned entries need both a backend and declared weights/training; three entries require information absent from this single-channel input.

A full catalog-wide reference-implementation equivalence study, independent clinical confirmation and fully re-nested participant bootstrap are outside the results delivered here. Conditional outer-prediction bootstrap uncertainty is labelled as such.
