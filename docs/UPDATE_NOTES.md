# Changes from the saved starter suite

## Software 4.0 motion integration

- Added exact-ID embedded/separate canonical motion import, signed physical coordinates, explicit pose adapter, quality masks and affine hardware synchronization.
- Added independent multitaper/harmonic-HAC and geometry-preserving switching-oscillator reference witnesses, calibrated-limit negative states and reference-sensitivity comparisons.
- Added M1–M6 mechanical outcomes, separate unseen-subject RMS and person-calibrated waveform readouts, subject-first severity/task summaries and a motion-only clinical comparator.
- Added training-only mechanical readout selection and an optional mechanical tie-break after mild capture; fixed the optional tuning-argument count and added a regression test.
- Added frozen/retrained motion retention, native-waveform compression checks, conditional subject uncertainty and motion-conditioned residual repeatability.
- Added selected-method coherence with explicit rank/replicate/model-fit gates; preserves destructive interference and unavailable attribution.
- Added gap-safe motion reduction, source/policy/clock cache identities, bounded temporary waveform packets, numbered/labelled exports, HTML links and motion inspection plots.
- Kept motion and clinical labels out of all study EMG algorithm hooks. The ordinary EMG-only entry retains motion disabled.
- Added native motion tests and an executed independent motion equation/source audit. MATLAB execution remains unavailable here; no patient result is claimed.

Both source benchmark PDFs are included unchanged. See `MOTION_CAPTURE.md` for schema, definitions, limitations and exact output files.

## Software 3.0 additions

- Replaced the eight-configuration generic sample with method-specific spaces, exhaustive small grids, parameter-value coverage, deterministic filling and two training-only beam/coordinate refinement rounds.
- Added fold-local adaptive search pools, training-only proposal extraction, selected held-out fill and independently scoped all-training deployment search. Shared caches never import another fold's outcome-dependent candidate pool into selection.
- Added search-space, refinement-trace and selected-parameter stability exports. Readout ridge remains separate from signal extraction.
- Expanded known-input calibration to 75 frequency/depth/pattern combinations, including low modulation and late/repeated bursts. Weak and late recovery have separate audit columns.
- Removed first-300-sample truncation from subspace inference; pooled all supported runs and added full-record overlapping atomic blocks with convergence diagnostics.
- Replaced IRASA linear warp interpolation with anti-alias down-warps and guarded sinc interpolation.
- Added explicit compatible preprocessing/analysis cross experiments with transform ownership, rejection reasons and cache identity.
- Moved the Kalman frequency-seed transform into its matched local-DPSS preprocessor, allowing it to share compatible DPSS preparation with the DPSS tracker.
- Bounded extraction to 32 candidates per batch; shared calibration transforms and released transforms after their last use. This changes memory/I/O scheduling, not sample selection.
- Added paired severe-capture, false-severe and coverage intervals, alongside mild capture, FPR and log loss.
- Added `START_HERE.m`, native adaptive/search/subspace/warp tests and independently executed revision-3 equation checks.

The implementation count remains 58 research entries. No unavailable wrapper was relabelled as implemented. MATLAB tests and participant analysis remain unexecuted here.
